TASK SHEET A - decide or fork (exact algebra)

You will receive several small "worlds" in JSON. For each world, compute the correct answer under the definitions below. The definitions are exact: follow them literally, and use exact rational arithmetic. Treat every world independently. Think as long as you need. At the very END of your reply, give exactly one fenced code block marked json containing a JSON list with one object per world (format in section 6).

1. WORLD FORMAT
- "generators": symbols, each with a grade: 0 (even) or 1 (odd). Generators need not commute with each other.
- "variables": universally quantified rational variables. Every law must hold for ALL rational values of the variables. Variables commute with everything.
- "parameters": unknown rational constants. They commute with everything.
- "laws": equations "lhs = rhs" in the generators, variables and parameters, in Python syntax: * is multiplication, ** is a power. The order of generator factors matters.
- "observations": items {"expr": E, "status": "nonzero"}. E is an expression in the generators only, and it is observed to be NONZERO. Below these are called demands.

2. LEVELS, in preference order: SUBSUMED < comm < graded < assoc
- SUBSUMED: every generator is a rational number.
- comm: all generators commute with each other.
- graded: x*y = (-1)^(|x||y|) * y*x for all generators x, y, where |x| is the grade. So odd generators anticommute with each other, and every odd generator squares to 0. This level exists only if some generator is odd.
- assoc: no extra rule (associative, not necessarily commutative).
- Admissible algebra: a nonzero unital associative algebra over the rationals Q, generated by the generators, that satisfies every law for all variable values and in which every demand is nonzero. At the comm or graded level it must also obey that level's rule.
- Viable level: an admissible algebra exists at that level. For SUBSUMED this means: some assignment of rational numbers to the generators satisfies every law (for all variable values) with every demand nonzero.

3. MENTIONS
- The mentions of a world are the subexpressions of each side of each law that contain a generator. They are exactly the nodes of the expression tree that sympy's parse_expr(side, evaluate=False) builds, and that tree FLATTENS repeated sums and products:
  - (a*b)*c is one product a*b*c. Its mentions are a, b, c and a*b*c. It does NOT mention a*b.
  - a*b + c*d mentions a, b, c, d, a*b, c*d and a*b + c*d.
  - (a*b)**2 mentions a, b, a*b and (a*b)**2.
  - a - b is a + (-1)*b, so it mentions a, b, -b and a - b.
  - 2*a*b mentions a, b and 2*a*b.
  - Mentions that are constant multiples of each other count separately, but identical polynomials count once. A subexpression that expands to 0 is not a mention.
- Live mention: a mention that is NOT identically zero in the freest associative algebra of the laws, i.e. the free associative algebra on the generators modulo the laws (no level rule added).

4. THE ANSWER
- F_occ = the first viable level.
- F_role = the first viable level at which some admissible algebra also keeps EVERY live mention nonzero. For SUBSUMED: some viable rational assignment keeps every live mention nonzero.
- CONTRADICTION: no level is viable. Either 1 = 0 follows from the laws, or some demand is forced to be 0.
- DETERMINED with level F: F_occ = F_role = F.
- FORK: F_occ != F_role.
  - The branches are ALL viable levels from F_occ up to F_role, inclusive, in preference order.
  - A non-last branch is the correct description exactly when the live mentions it kills are in fact zero. The last branch, F_role, is correct when they are not.
- Worlds with parameters: evaluate the answer (label plus level or branches) for each parameter value in {-3, -2, -1, 0, 1, 2, 3, 1/2}.
  - If it is the same for all of them, give that answer.
  - If it changes, answer UNDERDETERMINED.
- Decisive set, for FORK only: for each non-last branch, give a list Q of expressions in the generators such that:
  - every element of Q is nonzero in the last branch (in an admissible algebra of the last branch that keeps the live mentions nonzero), and
  - every admissible algebra of that non-last branch makes at least one element of Q equal to 0.
  Observing every element of Q nonzero would then exclude that branch. A live mention that the branch kills is often a good choice.

5. CONVENTIONS
- Write rationals exactly, e.g. "1/2". Never use decimals.
- Level names must be exactly: SUBSUMED, comm, graded, assoc.
- Expressions use the same syntax as the laws.

6. OUTPUT FORMAT
At the end of your reply, give ONE fenced json block with a JSON list, one object per world, for example:
```json
[
 {"id": "A-90", "label": "DETERMINED", "level": "comm"},
 {"id": "A-91", "label": "FORK", "branches": ["SUBSUMED", "comm", "assoc"], "decisive": [["x*y - y*x"], ["x*y*x"]]},
 {"id": "A-92", "label": "CONTRADICTION"},
 {"id": "A-93", "label": "UNDERDETERMINED"}
]
```
- "decisive" has one list per non-last branch, in branch order.
- The ids above are only a format example. Use the ids of the worlds you receive.
