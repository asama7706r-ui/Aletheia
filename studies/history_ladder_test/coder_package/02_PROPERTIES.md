# The 14 properties to report for each system

For each property, say whether it holds in the system as published. Here `a`, `b`, `c` are arbitrary elements of the system, `0` and `1` are its zero and unit, and the real numbers are the multiples of 1.

| key | property |
|---|---|
| P1 | 1 is not equal to 0 |
| P2 | the real numbers sit inside the system unchanged: distinct reals stay distinct, and adding, negating, multiplying and inverting reals gives the usual results |
| P3 | addition is associative: (a + b) + c = a + (b + c) |
| P4 | addition is commutative: a + b = b + a |
| P5 | multiplication is associative: (a*b)*c = a*(b*c) |
| P6 | multiplication is commutative: a*b = b*a |
| P7 | left distributivity: a*(b + c) = a*b + a*c |
| P8 | right distributivity: (a + b)*c = a*c + b*c |
| P9 | 0 is the identity of addition: a + 0 = a |
| P10 | 1 is the identity of multiplication: 1*a = a = a*1 |
| P11 | every element a has a negative -a with a + (-a) = 0 |
| P12 | no zero divisors: if a*b = 0 then a = 0 or b = 0 |
| P13 | every nonzero element a has an inverse a^-1 with a*a^-1 = 1 = a^-1*a |
| P14 | the system can be given a total order compatible with its operations, as the real numbers have: for all a, b exactly one of a < b, a = b, b < a; a < b implies a + c < b + c; and 0 < a, 0 < b imply 0 < a*b |

For P5, also note any weaker form that holds (for example, whether (a*a)*b = a*(a*b) holds). For P12 and P13, give an explicit pair or element when the property fails.
