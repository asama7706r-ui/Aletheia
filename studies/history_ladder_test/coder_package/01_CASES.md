# The 12 cases, and the source files for each

The systems are named as in the Wikipedia article W00 ("Hypercomplex number"). Read every file listed for a case. W00 is relevant to every case.

| case | system | source files |
|---|---|---|
| C1 | tessarines = bicomplex numbers | W00, W01, S01, S02, S03, S04 |
| C2 | multicomplex numbers (2^n dimensions, n >= 3; n = 2 is C1) | W00, W02, S04 |
| C3 | hyperbolic quaternions | W00, W03, S05 |
| C4 | split-biquaternions | W00, W04, S06 (via your transcription) |
| C5 | split-octonions | W00, W05 |
| C6 | complex octonions | W00, W06 |
| C7 | the tensor product H x H of two quaternion algebras (isomorphic to Cl3,1 and to 4x4 real matrices) | W00 |
| C8 | quaternionic matrix (H x H x H, isomorphic to 4x4 quaternionic matrices) | W00, W07 |
| C9 | trigintaduonions (32 dimensions) | W00, W08 |
| C10 | sexagintaquatronions (64 dimensions) | W00, W08 |
| C11 | centumduodetrigintanions (128 dimensions) | W00, W08 |
| C12 | ducentiquinquagintasexions (256 dimensions) | W00, W08 |

For C1, S01 to S03 are by James Cockle (1848-1849) and S04 is by Corrado Segre (1892). Code the case from its earliest author, and report the later author under `what_happened_next`, with quotations.
