## 1. Claims under test
E1 (primary). Given only a world's laws, the procedure decides:
- SUBSUMED: the unknown generators are known rational values;
- NEW_KIND: a genuinely new kind is needed, and in which family it lives (Section 2);
- CONTRADICTION: no nonzero associative algebra satisfies the laws;
- UNDERDETERMINED: the correct decision depends on the value of a free parameter.
It must do so better than three pre-registered baselines, and in particular without "silent collapse" (choosing a family that is too restrictive for the hidden truth, or a known value when a new kind is needed).
E2 (secondary). Given a law, its identity card (dimensions, validated data points, symmetries, state) and a proposed filled law, the procedure decides SAME_LAW_NEW_STATE / ANOTHER_LAW / INVALID better than three baselines.
Not tested: extracting laws from natural language; real scientific discovery; non-associative structures; speed.

## 2. Definitions (E1)
- Generators have a declared grade 0 or 1.
- Families (all associative and unital, over Q):
  - comm: all generators commute;
  - graded: x*y = (-1)^(|x||y|) y*x for all generators x, y (so odd generators square to 0);
  - assoc: no extra rule.
  - Restrictiveness order: comm < graded < assoc. If all grades are 0, graded coincides with comm.
- Hidden truth T: an algebra generated by the generators that satisfies all laws, given by a faithful witness (rational matrices, one per generator).
- true_family: the most restrictive family containing T (computed from the witness matrices).
- observed_nonzero: expressions in the generators (NOT shown to the procedure) that the world measures to be nonzero in T.
- Identifiability (required for every NEW_KIND and SUBSUMED world): (a) in every family strictly more restrictive than true_family, every algebra satisfying the laws kills at least one observed quantity, or no nonzero such algebra exists; (b) for NEW_KIND truths, no rational values of the generators satisfy the laws with all observed quantities nonzero.
- SUBSUMED truth: T = Q, each generator equal to a rational value; the laws hold and the observed quantities are nonzero at those values.

## 3. E1 world format (one JSON file per world in worlds\)
{
  "id": "E1-01",
  "experiment": "E1",
  "generators": [{"name": "a", "grade": 0}],
  "variables": ["t", "x"],
  "parameters": ["c"],
  "laws": ["a*a = -3", "(t + a*x)*(t - a*x) = t**2 + 3*x**2"]
}
- "variables" (optional): universally quantified commuting rationals. "parameters" (optional): unknown constants (commuting rationals).
- Laws are polynomial equations with exactly one "="; rational coefficients only (write 1/2, never 0.5); products of generators are non-commutative and written with "*"; integer powers "**" allowed; no division except by integer constants.
- Names are simple ASCII identifiers; avoid I, E, S, N, O, Q, pi and Python keywords.
- World files contain no comments, hints, categories or extra fields.
- Budgets: 1 to 4 generators; with 1/2/3/4 generators every law has non-commutative degree at most 9/7/5/4 after expansion; known values in SUBSUMED worlds are integers in -3..3 or +-1/2; when a parameter changes the decision, it already does so for values in {-3,-2,-1,0,1,2,3,1/2}.
- Style: write the laws as a scientist would state them in that world: mix expanded, factored and nested forms; include at least one law that states what the new object is used for (its purpose), not only defining relations; redundant consequences are allowed. Do not tailor laws to any presumed method.

## 4. E1 key format (key\key.json is one JSON list for E1 and E2)
{
  "id": "E1-01",
  "label": "SUBSUMED | NEW_KIND | CONTRADICTION | UNDERDETERMINED",
  "true_family": "comm | graded | assoc",
  "true_dim": 4,
  "witness": {"a": [["0", "-3"], ["1", "0"]]},
  "true_values": {"a": "1"},
  "true_parameter_values": {"c": "2"},
  "observed_nonzero": ["a*b - b*a"],
  "complete_presentation": true,
  "category": "free text",
  "notes": "free text"
}
- true_family, true_dim, witness, complete_presentation: NEW_KIND only. true_dim is the dimension (unit included) of the algebra generated by the witness. complete_presentation is true when the laws present T completely within true_family.
- true_values: SUBSUMED only. observed_nonzero: NEW_KIND and SUBSUMED.
- true_parameter_values: whenever the world has parameters and the label is not UNDERDETERMINED.

## 6. E2 world format, key and composition (16 worlds)
{
  "id": "E2-01",
  "experiment": "E2",
  "quantities": {"E": {"M": 1, "L": 2, "T": -2}},
  "law_original": "E = p**2/(2*m)",
  "filled_law": "E = p**2/(2*m) + K",
  "symmetries": [{"name": "parity", "map": {"p": "-p"}, "params": {"v": ["-1", "1"]}}],
  "ranges": {"p": ["1/2", "3"]},
  "validated": [{"inputs": {"p": "1", "m": "2", "K": "0"}, "output": "1/4", "tol": "1e-9"}],
  "deficit": {"inputs": {"p": "1", "m": "2", "K": "1"}, "output": "5/4", "tol": "1e-9"},
  "state_original": ["particle"],
  "state_filled": ["particle", "field"]
}
- Laws are explicit: a single declared symbol on the left.
- Symmetry maps may use only quantities of the law and the declared symmetry parameters.
- "ranges" is optional (default sampling range [1/2, 3]).
- Every validated point lists values for EVERY quantity appearing in either law.
- The original law fails the deficit point; the filled law fits it.
- Key entry: {"id": "E2-01", "label": "SAME_LAW_NEW_STATE | ANOTHER_LAW | INVALID", "detectable_by_card": true, "notes": "..."}.
- Meaning: SAME_LAW_NEW_STATE = the law is preserved and the state gains new objects (e.g., a new carrier); ANOTHER_LAW = the filled law is a different law (changed symmetry, broken validated behaviour, or a different system or regime); INVALID = the filled law is dimensionally inconsistent.
- Composition: SAME_LAW_NEW_STATE 6; ANOTHER_LAW 7 (at least 2 with detectable_by_card = false, i.e. the difference does not show in the given card items); INVALID 3.

## 7. Metrics, baselines, success criteria
E1 (only worlds passing key validation; the scorer checks witness laws, observed quantities, family, dimension and identifiability; if more than 20% of E1 worlds fail validation, E1 is VOID):
- correct: the label matches; NEW_KIND also needs family = true_family; SUBSUMED also needs the true values among the procedure's listed values.
- silent collapse rate: over NEW_KIND truths, the fraction answered SUBSUMED or with a strictly more restrictive family.
- over-looseness rate: over NEW_KIND truths with true_family comm or graded, the fraction answered with a strictly looser family.
- Baselines: B1 impose old rules always (known value if any rational solution, else comm); B2 never impose rules (assoc; known value only if the assoc mold is one-dimensional); B3 relax only on loud collapse (known value if any rational solution; then the first of comm, graded, assoc whose mold is nontrivial).
- S1: accuracy >= 0.70.
- S2: accuracy minus the best baseline's accuracy >= 0.15, and one-sided exact McNemar p < 0.05 against that baseline.
- S3: silent collapse rate <= 0.15.
- S4: at most one CONTRADICTION truth answered SUBSUMED or NEW_KIND.
- Outcome: PASS if S1-S4 all hold; PARTIAL if only S1 and S3 hold; FAIL otherwise; VOID as above.
- The "stable" flag in the outputs is reported but does not change any label.
E2:
- T1: recall on ANOTHER_LAW worlds with detectable_by_card = true >= 0.80.
- T2: false alarms on SAME_LAW_NEW_STATE worlds <= 1/6.
- T3: INVALID worlds detected >= 2/3.
- T4: balanced accuracy above every baseline (C1 accept any filler; C2 flag any change; C3 dimensions only).
- PASS if T1-T4 all hold, else FAIL.
Interpretation (fixed now): PASS = evidence that the role mechanism adds value beyond loud-collapse detection on unseen formal worlds; PARTIAL = it works but is not shown to be better than simple baselines; FAIL = the hypothesis in its current form is not supported and returns to design; VOID = rerun with new worlds. No outcome is evidence of real scientific discovery ability.

## 10. Known limitations (declared before the test)
- The generator and the procedure author are models of the same family.
- n is small (a pilot; wide confidence intervals).
- The truncated word engine can miss collapses (it errs toward "alive").
- The family set excludes non-associative structures.
- E2 cannot see differences outside the card (a declared blind spot).
- Subsumption search for positive-dimensional cases is limited to the declared grid.
